Phím tắt nhanh (áp dụng mọi panel)

Phím tắtChức năng
F12 / Ctrl+Shift+IMở/đóng DevTools
Ctrl+Shift+JMở thẳng Console
Ctrl+Shift+CBật chế độ Inspect element
Ctrl+Shift+MBật Device Toolbar (giả lập mobile)
Ctrl+Shift+PMở Command Menu (chạy mọi lệnh DevTools)
Ctrl+LXoá Console
F8 / F10 / F11Resume / Step over / Step into (khi debug)

Cú pháp Console hay dùng

LệnhCông dụng
console.log/warn/error(x)In log theo mức độ
console.table(arr)Hiện mảng/object dạng bảng
console.group()/groupEnd()Nhóm log lại
$0, $1, $2…Phần tử vừa chọn trong Elements (gần nhất = $0)
$(sel) / $$(sel)querySelector / querySelectorAll rút gọn
monitor(fn) / unmonitor(fn)Log mỗi lần hàm được gọi
copy(obj)Copy giá trị vào clipboard
clear()Xoá console

Mẹo nhanh

• Gõ thử console.table([1,2,3]), $0, hoặc $$(".x") vào ô Console phía trên để xem phản hồi mô phỏng.
• Bấm từng nút trong mỗi tab để đọc giải thích công dụng + cú pháp ngay bên dưới.
• Đây là bản mô phỏng UI để học; hãy mở DevTools thật (F12) trên trình duyệt để thực hành trên dữ liệu thật.
